# Sharingan AR · Unreal 5.8

Implementación añadida a esta carpeta: cámara frontal con seguimiento de cara ARCore y ojos Sharingan; cámara trasera para AR de mundo. ARCore limita el seguimiento facial nativo a la cámara frontal. Configuración Android: Vulkan, minSdk 26 y targetSdk 35.

Antes de empaquetar, ejecuta `Engine/Extras/Android/SetupAndroid.bat` de UE 5.8. El equipo necesita .NET 10 para que UnrealBuildTool pueda compilar el módulo.
